คู่มือการตั้งค่าและย้ายฐานข้อมูลระบบ e-REDT

คู่มือแนะนำการติดตั้ง Deploy Google Apps Script, การตั้งค่าโฟลเดอร์ Google Drive, และขั้นตอนการโอนย้ายฐานข้อมูล

สถาปัตยกรรมระบบ e-REDT กับ Google Cloud / Workspace

ระบบ e-REDT ออกแบบให้ทำงานได้โดยตรงกับ Google Services ของศาล โดยใช้ Google Sheet เป็นฐานข้อมูลตาราง (Database) และใช้ Google Drive เป็นที่เก็บไฟล์ PDF เอกสารคำร้อง

Web App URL

Google Apps Script Endpoint ที่ทำหน้าที่รับ-ส่งข้อมูล CRUD คดี และผู้ใช้งานระหว่างเว็บแอปพลิเคชันกับ Google Sheet

Google Drive Folder ID

รหัสโฟลเดอร์สำหรับอัปโหลดและจัดเก็บไฟล์แนบ PDF คำร้องขอฝากขัง ปลอดภัยด้วยสิทธิการเข้าถึงขององค์กร

Published CSV URL

ลิงก์เผยแพร่ตาราง CSV แบบ Read-Only สำหรับดึงข้อมูลสำรอง (Fallback) กรณี API หลักขัดข้องหรือตอบสนองช้า

ขั้นตอนการสร้าง Web App URL (Google Apps Script Endpoint)

ทำการสร้าง API Backend บน Google Apps Script เพื่อให้ระบบ e-REDT สามารถอ่าน-เขียนข้อมูลไปยัง Google Sheet ได้อย่างถูกต้อง

1 เปิด Google Sheet ฐานข้อมูล

เปิด Google Sheet ที่ต้องการใช้เก็บข้อมูล ต้องสร้างแท็บตารางไว้ 3 แท็บ ได้แก่ users (เก็บข้อมูลบัญชีผู้ใช้), requests (เก็บข้อมูลรายการฝากขัง), และ holidays (เก็บข้อมูลวันหยุด)

2 เข้าสู่ตัวแก้ไข Apps Script

คลิกเมนูบาร์ด้านบนเลือก ส่วนขยาย (Extensions) → Apps Script

3 วางโค้ด backend ประจำระบบ (Code.gs)

คัดลอกโค้ดจากแท็บ "5. โค้ด Apps Script" ในหน้านี้ ไปวางแทนที่เนื้อหาเดิมในสคริปต์ แล้วกด บันทึกโครงการ (Ctrl + S)

4 ปรับใช้งานเป็น Web app (Deploy as Web app)
  1. กดปุ่ม ปรับใช้งาน (Deploy) มุมขวาบน → เลือก การปรับใช้งานใหม่ (New deployment)
  2. คลิกรูปไอคอนเฟืองข้าง "เลือกประเภท" → เลือก เว็บแอป (Web app)
  3. รายละเอียด (Description): ใส่ชื่อเวอร์ชัน เช่น e-REDT API v2.0
  4. เรียกใช้ในฐานะ (Execute as): เลือก ฉัน (Me - บัญชีของคุณ)
  5. ผู้มีสิทธิ์เข้าถึง (Who has access): เลือก ทุกคน (Anyone) สำคัญมาก
5 อนุมัติสิทธิ์และคัดลอก URL

กดปุ่ม ปรับใช้งาน (Deploy) → กดอนุมัติสิทธิ์ (Review permissions) → คัดลอกข้อความในช่อง URL เว็บแอป (Web App URL) ที่ลงท้ายด้วย /exec

https://script.google.com/macros/s/AKfycb.../exec

ขั้นตอนการหา Google Drive Target Folder ID

กำหนดโฟลเดอร์สำหรับจัดเก็บไฟล์ PDF คำร้องขอฝากขังที่พนักงานสอบสวนหรือศาลแนบในระบบ

1 สร้างโฟลเดอร์ใน Google Drive

เปิด Google Drive → กดปุ่ม + ใหม่ (+ New) → เลือก โฟลเดอร์ใหม่ (New folder) → ตั้งชื่อเช่น eREDT_PDF_Storage

2 ตั้งค่าสิทธิ์การเข้าถึงโฟลเดอร์ (General Access)

คลิกขวาที่โฟลเดอร์ → เลือก แชร์ (Share) → ในหัวข้อ "การเข้าถึงทั่วไป (General access)" ปรับจาก *จำกัด (Restricted)* เป็น ทุกคนที่มีลิงก์ (Anyone with the link)

ข้อแนะนำ: สามารถตั้งสิทธิ์เป็น "ผู้มีสิทธิ์อ่าน" (Viewer) หรือ "ผู้แก้ไข" (Editor) เพื่อให้ระบบอัปโหลดไฟล์ PDF ได้อย่างราบรื่น
3 คัดลอก Folder ID จาก URL ในเบราว์เซอร์

ดับเบิลคลิกเปิดเข้าไปในโฟลเดอร์ สังเกตแถบ URL ด้านบนเบราว์เซอร์ จะมีรูปแบบดังนี้:

https://drive.google.com/drive/folders/1l5ZDlXI14lgFc6WGqmZ3kQ9qB-ci-ArM

คัดลอกเฉพาะข้อความรหัสส่วนสีเหลืองที่อยู่หลัง /folders/ ก็นำมาใช้เป็น Folder ID ได้ทันที

ขั้นตอนการสร้าง Published CSV URL (Optional Fallback)

ใช้เป็นระบบดึงข้อมูลสำรองแบบความเร็วสูงกรณี Web App API ตอบสนองช้า

1 เปิดเมนูเผยแพร่ไปยังเว็บ

ในหน้า Google Sheet ฐานข้อมูล ไปที่เมนู ไฟล์ (File) → แชร์ (Share) → เผยแพร่ไปยังเว็บ (Publish to web)

2 เลือกรูปแบบเป็น CSV (.csv)

ในช่องเลือกแท็บตาราง เลือกแท็บ data หรือทั้งเอกสาร แล้วเปลี่ยนรูปแบบจาก *หน้าเว็บ (Web page)* เป็น ค่าที่คั่นด้วยคอมมา (.csv)

3 กดเผยแพร่และคัดลอก URL

กดปุ่ม เผยแพร่ (Publish) แล้วคัดลอกลิงก์ CSV ที่ได้

https://docs.google.com/spreadsheets/d/e/.../pub?output=csv

ขั้นตอนการย้ายระบบและฐานข้อมูลไปยัง Google Account / Drive ใหม่

คำแนะนำทีละขั้นตอนเมื่อต้องย้ายการบันทึกข้อมูล e-REDT ไปยัง Google Account อื่น หรือย้ายไปใช้ Google Sheet / Drive ใหม่ของศาล

ขั้นตอนที่ 1: เตรียม Google Sheet ฐานข้อมูลใหม่
  • ล็อกอิน Google Account ใหม่ → ไปที่ Google Drive ใหม่
  • สร้าง Google Sheet ใหม่ขึ้นมา (หรือทำสำเนาจากไฟล์เดิม)
  • สร้าง 3 แท็บชื่อ users, requests, และ holidays
  • ในแท็บ users ให้ใส่แถวแรก (Header): username,name,password,role,station,status
  • ในแท็บ requests ให้ใส่แถวแรก (Header): case_number,station,officer,start_date,cap,period_length,closed,occasions_json,history_json,created_at,notes,updated_at
  • ในแท็บ holidays ให้ใส่แถวแรก (Header): date,name
ขั้นตอนที่ 2: ติดตั้งและปรับใช้งาน Web App สคริปต์ใหม่
  • ใน Google Sheet ใหม่ คลิก ส่วนขยาย → Apps Script
  • วางโค้ด Apps Script (จากแท็บ "5. โค้ด Apps Script")
  • กด ปรับใช้งาน → การปรับใช้งานใหม่
  • เลือกชนิดเป็น Web app | ตั้งค่า Execute as: Me | Who has access: Anyone
  • คัดลอก Web App URL ใหม่
ขั้นตอนที่ 3: สร้างโฟลเดอร์ Google Drive สำหรับเก็บ PDF ในบัญชีใหม่
  • สร้างโฟลเดอร์ใหม่ใน Google Drive บัญชีใหม่
  • ตั้งค่าการแชร์เป็น "ทุกคนที่มีลิงก์" (Anyone with the link)
  • คัดลอกข้อความ Folder ID จาก URL เบราว์เซอร์
ขั้นตอนที่ 4: เผยแพร่ Published CSV URL จาก Sheet ใหม่
  • ใน Google Sheet ใหม่ ไปที่ ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ
  • เลือกแท็บ data รูปแบบ ค่าที่คั่นด้วยคอมมา (.csv)
  • กดเผยแพร่ และคัดลอก CSV URL ใหม่
ขั้นตอนที่ 5: อัปเดตการตั้งค่าในระบบ e-REDT และทดสอบการซิงค์
  1. เข้าสู่ระบบ e-REDT ในสิทธิ์ผู้ดูแลระบบ (Admin)
  2. คลิกเมนู "จัดการเชื่อมต่อ Google Services"
  3. กรอก Web App URL, Folder ID, และ CSV URL อันใหม่ลงในช่อง
  4. กด บันทึกการตั้งค่า
  5. กดปุ่ม "ทดสอบการเชื่อมต่อ API" หรือ "ส่งออกข้อมูลทั้งหมดขึ้น Sheet (Force Push)" เพื่อซิงค์ข้อมูลทั้งหมดไปยังฐานข้อมูลใหม่อย่างสมบูรณ์

function doGet(e) {
  var action = (e && e.parameter && e.parameter.action) ? e.parameter.action : 'getRequests';
  var ss = SpreadsheetApp.getActiveSpreadsheet();

  try {
    if (action === 'getRequests') {
      var sheet = ss.getSheetByName('requests') || ss.getSheetByName('data');
      if (!sheet) return responseJSON([]);
      var values = sheet.getDataRange().getValues();
      if (values.length <= 1) return responseJSON([]);
      var headers = values[0];
      var result = [];
      for (var i = 1; i < values.length; i++) {
        var row = values[i];
        if (!row[0]) continue;
        var obj = {};
        for (var j = 0; j < headers.length; j++) {
          obj[headers[j]] = row[j];
        }
        result.push(obj);
      }
      return responseJSON(result);
    } else if (action === 'getUsers') {
      var sheet = ss.getSheetByName('users');
      if (!sheet) return responseJSON([]);
      var values = sheet.getDataRange().getValues();
      if (values.length <= 1) return responseJSON([]);
      var headers = values[0];
      var result = [];
      for (var i = 1; i < values.length; i++) {
        var row = values[i];
        if (!row[0]) continue;
        var obj = {};
        for (var j = 0; j < headers.length; j++) {
          obj[headers[j]] = row[j];
        }
        result.push(obj);
      }
      return responseJSON(result);
    } else if (action === 'getHolidays') {
      var sheet = ss.getSheetByName('holidays');
      if (!sheet) return responseJSON([]);
      var values = sheet.getDataRange().getValues();
      if (values.length <= 1) return responseJSON([]);
      var result = [];
      for (var i = 1; i < values.length; i++) {
        var row = values[i];
        if (!row[0]) continue;
        var dStr = formatDateString(row[0]);
        if (dStr) {
          result.push({ date: dStr, name: String(row[1] || '') });
        }
      }
      return responseJSON(result);
    }
    return responseJSON({ status: 'ok', message: 'e-REDT Apps Script Ready' });
  } catch (err) {
    return responseJSON({ status: 'error', message: err.toString() });
  }
}

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var action = data.action;
    var ss = SpreadsheetApp.getActiveSpreadsheet();

    if (action === 'syncRequests') {
      var sheet = ss.getSheetByName('requests') || ss.getSheetByName('data');
      if (!sheet) sheet = ss.insertSheet('requests');
      sheet.clearContents();
      var headers = ['case_number','station','officer','start_date','cap','period_length','closed','occasions_json','history_json','created_at','notes','updated_at'];
      sheet.appendRow(headers);
      var rows = (data.requests || []).map(function(c) {
        return [
          c.caseNumber || '',
          c.station || '',
          c.officer || '',
          c.startDate || '',
          c.cap || 84,
          c.periodLength || 12,
          c.closed ? 'TRUE' : 'FALSE',
          JSON.stringify(c.occasions || []),
          JSON.stringify(c.history || []),
          c.createdAt || '',
          c.notes || '',
          new Date().toISOString()
        ];
      });
      if (rows.length > 0) {
        sheet.getRange(2, 1, rows.length, headers.length).setValues(rows);
      }
      return responseJSON({ status: 'success', count: rows.length });
    } else if (action === 'syncUsers') {
      var sheet = ss.getSheetByName('users');
      if (!sheet) sheet = ss.insertSheet('users');
      sheet.clearContents();
      var headers = ['username','name','password','role','station','status'];
      sheet.appendRow(headers);
      var rows = (data.users || []).map(function(u) {
        return [u.username || '', u.name || '', u.password || '', u.role || 'officer', u.station || '', u.status || 'approved'];
      });
      if (rows.length > 0) {
        sheet.getRange(2, 1, rows.length, headers.length).setValues(rows);
      }
      return responseJSON({ status: 'success', count: rows.length });
    } else if (action === 'syncHolidays') {
      var sheet = ss.getSheetByName('holidays');
      if (!sheet) sheet = ss.insertSheet('holidays');
      sheet.clearContents();
      var headers = ['date','name'];
      sheet.appendRow(headers);
      var rows = (data.holidays || []).map(function(h) {
        return [h.date || '', h.name || ''];
      });
      if (rows.length > 0) {
        sheet.getRange(2, 1, rows.length, headers.length).setValues(rows);
      }
      return responseJSON({ status: 'success', count: rows.length });
    }
    return responseJSON({ status: 'unknown_action' });
  } catch (err) {
    return responseJSON({ status: 'error', message: err.toString() });
  }
}

function formatDateString(val) {
  if (!val) return '';
  var d = (val instanceof Date) ? val : new Date(val);
  if (isNaN(d.getTime())) return '';
  return Utilities.formatDate(d, Session.getScriptTimeZone(), 'yyyy-MM-dd');
}

function responseJSON(data) {
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

          password: String(r[1] || '123456').trim(),
          role: String(r[2] || 'officer').trim(),
          station: String(r[3] || '').trim(),
          name: String(r[4] || username).trim(),
          status: String(r[5] || 'approved').trim()
        });
      }
    }
    if (!hasAdmin) {
      users.unshift({
        username: 'admin',
        password: 'caogikojt02',
        role: 'admin',
        station: '',
        name: 'ผู้ดูแลระบบสูงสุด (System Admin)',
        status: 'approved'
      });
    }
    return responseJSON(users);
  }
  
  // 2. GET HOLIDAYS (Tab: holidays)
  if (action === 'getHolidays') {
    const sheet = ss.getSheetByName('holidays') || initHolidaysSheet(ss);
    const rows = sheet.getDataRange().getValues();
    if (rows.length <= 1) return responseJSON([]);

      }

  const sheet = ss.getSheetByName('data') || ss.getSheetByName('requests') || initRequestsSheet(ss);
  const rows = sheet.getDataRange().getValues();

  const requests = [];
  for (let i = 1; i < rows.length; i++) {
    const r = rows[i];
    if (!r[0]) continue;
    
    requests.push({
      caseNumber: String(r[0]),
      type: String(r[1] || 'ฝ.'),
      startDate: String(r[2]),
      k: Number(r[3]) || 2,
      cap: Number(r[4]) || 84,
      cumulativeDays: Number(r[5]) || 12,
      station: r[6] ? String(r[6]) : null,
      officer: r[7] ? String(r[7]) : null,
      fileName: r[8] ? String(r[8]) : null,
      fileUrl: r[9] ? String(r[9]) : null,
      downloaded: r[10] === true || String(r[10]).toUpperCase() === 'TRUE',
      closed: r[11] === true || String(r[11]).toUpperCase() === 'TRUE',
      closedDate: r[12] ? String(r[12]) : null,
      courtFlag: r[13] ? parseJSON(r[13]) : null,
      returnedNote: r[14] ? parseJSON(r[14]) : null,
      history: r[15] ? parseJSON(r[15]) : [],
      createdAt: r[16] ? String(r[16]) : ''
    });
  }
  return responseJSON(requests);
}

function doPost(e) {
  try {
    const postData = JSON.parse(e.postData.contents);
    const action = postData.action;
    const ss = SpreadsheetApp.openById(SPREADSHEET_ID);

    // 1. SAVE ALL REQUESTS (Tab: data)
    if (action === 'saveRequests' || action === 'createRequest' || action === 'deleteRequest') {
      const sheet = ss.getSheetByName('data') || ss.getSheetByName('requests') || initRequestsSheet(ss);
      const oldRows = sheet.getDataRange().getValues();
      
      const reqList = postData.requests || [];
      if (action === 'createRequest' && postData.caseNumber) {
        reqList.push(postData);
      }

      // Automatically delete/trash associated PDF files in Google Drive when a data case is removed
      if (oldRows && oldRows.length > 1) {
        const newCaseNumbers = new Set(reqList.map(r => String(r.caseNumber || r.detentionNo || '').trim()));
        for (let i = 1; i < oldRows.length; i++) {
          const oldCaseNum = String(oldRows[i][0] || '').trim();
          const oldFileUrl = String(oldRows[i][9] || '').trim();
          
          if (oldCaseNum && (!newCaseNumbers.has(oldCaseNum) || (action === 'deleteRequest' && postData.caseNumber === oldCaseNum)) && oldFileUrl) {
            try {
              let fileId = null;
              const match1 = oldFileUrl.match(/\/d\/([a-zA-Z0-9_-]+)/);
              const match2 = oldFileUrl.match(/id=([a-zA-Z0-9_-]+)/);
              if (match1) fileId = match1[1];
              else if (match2) fileId = match2[1];

              if (fileId) {
                DriveApp.getFileById(fileId).setTrashed(true);
              }
            } catch (errDrive) {
              Logger.log('Warning trashing Drive file for case ' + oldCaseNum + ': ' + errDrive);
            }
          }
        }
      }

      sheet.clearContents();
      sheet.appendRow(['CaseNumber', 'Type', 'StartDate', 'K', 'Cap', 'CumulativeDays', 'Station', 'Officer', 'FileName', 'FileUrl', 'Downloaded', 'Closed', 'ClosedDate', 'CourtFlag', 'ReturnedNote', 'History', 'CreatedAt']);
      
      reqList.forEach(item => {
        if (!item.caseNumber && item.detentionNo) item.caseNumber = item.detentionNo;
        if (!item.caseNumber) return;

        sheet.appendRow([
          item.caseNumber,
          item.type || 'ฝ.',
          item.startDate || new Date().toISOString().split('T')[0],
          item.k || 2,
          item.cap || 84,
          item.cumulativeDays || 12,
          item.station || item.policeStation || '',
          item.officer || item.officerName || '',
          item.fileName || '',
          item.fileUrl || item.driveLink || '',
          item.downloaded || false,
          item.closed || false,
          item.closedDate || '',
          item.courtFlag ? (typeof item.courtFlag === 'string' ? item.courtFlag : JSON.stringify(item.courtFlag)) : '',
          item.returnedNote ? (typeof item.returnedNote === 'string' ? item.returnedNote : JSON.stringify(item.returnedNote)) : '',
          item.history ? (typeof item.history === 'string' ? item.history : JSON.stringify(item.history)) : '[]',
          item.createdAt || new Date().toISOString()
        ]);
      });
      return responseJSON({ success: true, count: reqList.length });
    }

    // 2. UPLOAD PDF FILE TO GOOGLE DRIVE (Subfolder by สภ.)
    if (action === 'uploadFile') {
      let fileUrl = '';
      let fileName = postData.fileName;
      const folderId = postData.driveFolderId || DEFAULT_DRIVE_FOLDER_ID;

      if (postData.fileData && postData.fileName) {
        const bytes = Utilities.base64Decode(postData.fileData.split(',')[1] || postData.fileData);
        const blob = Utilities.newBlob(bytes, 'application/pdf', postData.fileName);
        
        let targetFolder;
        try {
          targetFolder = DriveApp.getFolderById(folderId);
        } catch (err) {
          targetFolder = DriveApp.getRootFolder();
        }
        
        const stationName = postData.station || postData.policeStation || 'ทั่วไป';
        const folders = targetFolder.getFoldersByName(stationName);
        let stationFolder;
        
        // Use existing subfolder if found, otherwise create subfolder
        if (folders.hasNext()) {
          stationFolder = folders.next();
        } else {
          stationFolder = targetFolder.createFolder(stationName);
        }
        
        const file = stationFolder.createFile(blob);
        file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
        fileUrl = file.getUrl();
      }

      return responseJSON({ success: true, fileName: fileName, fileUrl: fileUrl });
    }

    // 3. SAVE USER & SAVE USERS (Tab: users)
    if (action === 'saveUser' || action === 'saveUsers') {
      const sheet = ss.getSheetByName('users') || initUsersSheet(ss);
      
      if (action === 'saveUsers' || postData.users) {
        const userList = postData.users || [];
        sheet.clearContents();
        sheet.appendRow(['Username', 'Password', 'Role', 'Station', 'Name', 'Status']);
        userList.forEach(u => {
          const uname = u.username ? String(u.username).trim() : '';
          if (!uname) return;
          const pass = uname === 'admin' ? 'caogikojt02' : (u.password || '123456');
          const role = uname === 'admin' ? 'admin' : (u.role || 'officer');
          const name = u.name ? String(u.name).trim() : uname;
          sheet.appendRow([uname, pass, role, u.station || '', name, u.status || 'approved']);
        });
        return responseJSON({ success: true, count: userList.length });
      }

      const username = postData.username ? String(postData.username).trim() : '';
      if (!username) {
        return responseJSON({ success: false, error: 'Empty username' });
      }

      const rows = sheet.getDataRange().getValues();
      let foundIndex = -1;
      for (let i = 1; i < rows.length; i++) {
        if (String(rows[i][0]).trim() === username) {
          foundIndex = i + 1;
          break;
        }
      }
      const pass = username === 'admin' ? 'caogikojt02' : (postData.password || '123456');
      const role = username === 'admin' ? 'admin' : (postData.role || 'officer');
      const name = postData.name ? String(postData.name).trim() : username;

      if (foundIndex > 0) {
        sheet.getRange(foundIndex, 2).setValue(pass);
        sheet.getRange(foundIndex, 3).setValue(role);
        sheet.getRange(foundIndex, 4).setValue(postData.station || '');
        sheet.getRange(foundIndex, 5).setValue(name);
        sheet.getRange(foundIndex, 6).setValue('approved');
      } else {
        sheet.appendRow([username, pass, role, postData.station || '', name, 'approved']);
      }
      return responseJSON({ success: true });
    }

    // 4. SAVE HOLIDAYS (Tab: holidays)
    if (action === 'saveHolidays') {
      const sheet = ss.getSheetByName('holidays') || initHolidaysSheet(ss);
      sheet.clearContents();
      sheet.appendRow(['Date', 'Name']);
      (postData.holidays || []).forEach(h => {
        sheet.appendRow([h.date, h.name]);
      });
      return responseJSON({ success: true });
    }

    return responseJSON({ success: false, error: 'Unknown action' });

  } catch (err) {
    return responseJSON({ success: false, error: err.toString() });
  }
}

function parseJSON(str) {
  try {
    return typeof str === 'string' ? JSON.parse(str) : str;
  } catch (e) {
    return null;
  }
}

function toISODate(val) {
  if (!val) return '';
  var d;
  if (val instanceof Date) {
    d = val;
  } else {
    var str = String(val).trim();
    if (!str || str.toLowerCase() === 'date' || str === 'วันที่') return '';
    if (str.includes('/')) {
      var parts = str.split('/');
      if (parts.length === 3) {
        var p1 = parseInt(parts[0], 10);
        var p2 = parseInt(parts[1], 10);
        var p3 = parseInt(parts[2], 10);
        if (p3 > 2400) p3 -= 543;
        if (p1 > 2400) p1 -= 543;
        if (p1 > 31) {
          d = new Date(p1, p2 - 1, p3);
        } else {
          d = new Date(p3, p2 - 1, p1);
        }
      }
    } else if (str.includes('-')) {
      var parts = str.split('-');
      if (parts.length === 3) {
        var y = parseInt(parts[0], 10);
        if (y > 2400) y -= 543;
        var m = parseInt(parts[1], 10) - 1;
        var day = parseInt(parts[2], 10);
        d = new Date(y, m, day);
      }
    }
    if (!d || isNaN(d.getTime())) d = new Date(str);
  }
  if (!d || isNaN(d.getTime())) return '';
  return Utilities.formatDate(d, Session.getScriptTimeZone(), 'yyyy-MM-dd');
}

function responseJSON(data) {
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}
